Kopírovat jídlo — celý flow

One interactive walk through the locked decisions: tap a meal on today → MealEditor → … menu → Kopírovat jídlo → D′ destination picker → confirm. Merging is silent — the picker never mentions occupancy; only the undo toast remains. Everything is clickable; use the phone, or the step rail / Zpět · Reset below.
