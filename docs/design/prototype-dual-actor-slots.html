Day-view dual-actor slot layout

Standalone static mock — no build, no seeded data, opens straight in a browser. Three structurally different layouts for a day-view slot showing both the mother's and the child's meal separately, plus the single-actor collapse for breastfed/solids feeding stages. Fixture day deliberately varies item count per slot — breakfast: 1 item (mother, with a conflict), lunch: 3 items each (both actors, no conflict), snack: 5 items (mother, longer names, one conflicting), dinner: 5 items (baby, longer names, one baby-only conflict) — so each variant can be judged with a single item, a short list, and a long, wrapping/truncating one.
