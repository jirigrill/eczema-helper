▸ FamilyGrid — onSelect: (familyId) => void, activeFamilyIds?: FamilyId[], eliminatedFamilyIds?: FamilyId[]

Flat 4-column grid of family tiles. One tile per FAMILIES entry (13 total). Visual states: neutral (white, default), active (white, no badge — family has items in meal), danger (danger tint + ! badge — family contains an eliminated allergen). Active takes precedence over danger.

neutral (default)

activeFamilyIds=['fruit'] (white tile, no badge)

eliminatedFamilyIds=['dairy'] (danger tint + !)

▸ FamilyDrillIn — familyId: FamilyId, inMealFoodIds?: string[], eliminatedAllergenIds?: string[], customFoods?: {foodId, name}[], onAddFood: (foodId, name) => void, onBack: () => void

Drill-in view for a single family. Foods grouped by allergenId (allergen header + food chips). Loose foods (allergenIds=[]) shown under "bez alergenu". States: neutral, success (in meal), danger (allergen eliminated). The Vlastní (custom) family lists previously-typed custom foods passed via customFoods under "Dříve zadané", or an empty hint when none exist. onBack returns to FamilyGrid.

▸ AllergenDrillIn — familyId: FamilyId, selected?: string[] (bindable), variant?: 'primary' | 'danger', onBack: () => void

Questionnaire allergen selector — one level shallower than FamilyDrillIn. Shows allergen chips for the given family. Chips toggle allergen ids into/out of selected[]. Used in steps 3 and 4 of onboarding. Single-allergen families are never passed here — collapse is handled by the parent page.

🫘 Luštěniny

familyId='legumes', selected=['soy'], variant='primary'

🥜 Ořechy a semínka

familyId='nuts-seeds', selected=['nuts'], variant='danger'
