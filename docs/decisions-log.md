# Decisions log

Settled, implemented decisions that are worth recording but not worth a full ADR. Each line is the decision as it stands today; the fuller reasoning (and any rejected alternatives) lives in git history under the original ADR file noted in parentheses. This is also the go-forward home for ordinary settled decisions — reserve a numbered ADR in `docs/adr/` for calls that constrain not-yet-built work or would need a deliberate revision to reverse.

- **Meals are day-granular.** `Meal` is keyed by `date` + `mealType`; there are no user-facing meal times, and `createdAt` / `updatedAt` are system-stamped for audit. Breastmilk allergen transit is too diffuse for hour precision, and the rest of the model is already day-keyed. *(was ADR-0003)*
- **In-memory port adapters were dropped.** The hand-written `InMemory*` fakes for `ScheduleRepository` / `QuestionnaireRepository` had no consumers and were removed; adapters are tested against `fake-indexeddb`. *(was ADR-0013)*
- **Meal logging is commit-gated with fixed-at-entry type.** The `/meal` flow builds a working meal in memory and persists it only on the `Uložit` commit; the meal type is chosen at entry and not mutable mid-edit (no move/switch pills); deleting a whole meal is an explicit destructive-confirm action. *(was ADR-0018)*
- **Food-source subgroup is a second presentation axis.** A family's foods can cluster under a curated `familySources` subgroup (e.g. Kravské / Ovčí / Kozí / Rostlinné, S lepkem / Bez lepku) above the allergen axis — applied only to families with ≥ 5 foods and an authored entry, unsourced foods falling into a trailing *Ostatní*. Source is presentation-only and never enters the trigger path; the former `bez alergenu` grouping was dropped because it read as a false safety claim. *(was ADR-0019)*
- **Unlogged meal-slot rows are tappable add-entry points.** In `MealCard`, an unlogged slot row is a link that opens `/meal` with that slot's meal type pre-selected — a deliberate exception to the otherwise FAB-only write path. *(was ADR-0020)*
